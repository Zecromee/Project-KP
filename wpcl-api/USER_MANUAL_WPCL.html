Pengenalan WPCL

APA ITU WPCL?

WPCL (Workstation Passenger Check List) adalah aplikasi digital untuk mencatat hasil pemeriksaan kondisi sarana kereta api penumpang. Seluruh proses pemeriksaan — dari pengisian checklist hingga cetak laporan PDF — dilakukan secara digital.

🔍
Pemeriksaan Digital

Checklist CCTV, PIDS Luar, PIDS Dalam, WiFi per gerbong — tanpa kertas

🔧
Locotrack

Pencatatan kondisi lokomotif pendukung secara terstruktur

📄
Auto-Print PDF

Laporan resmi otomatis tercetak setelah penyimpanan data

📱
Mobile-Friendly

Bisa digunakan langsung di lapangan melalui HP Android

BAB B — MEMULAI

Install Aplikasi Mobile

1
Minta file APK kepada administrator WPCL. File bernama: wpcl_app-release.apk
2
Buka file APK di HP Android. Jika muncul peringatan "Sumber tidak dikenal", pilih Izinkan atau Install dari sumber ini.
3
Tunggu proses instalasi selesai (~1 menit). Aplikasi WPCL akan muncul di menu HP.
4
Buka aplikasi WPCL. Halaman "Identitas Pemeriksaan" akan terbuka.
💡
Tips: Setelah install, pastikan HP terhubung ke internet sebelum membuka aplikasi.

Setup Koneksi API

1
Buka aplikasi WPCL → klik ikon ⚙️ (gear) di pojok kanan atas.
2
Masukkan URL API server:
http://<IP_SERVER>:8000/api
3
Contoh URL:
  • Lokal: http://192.168.1.5:8000/api
  • Online: https://wpcl-api.vercel.app/api
4
Klik "Simpan".
✅
Jika berhasil, aplikasi akan menampilkan daftar kereta di halaman "Identitas Pemeriksaan".

Cara Mencari IP Server

📌
IP server adalah alamat PC/laptop yang menjalankan backend WPCL. HP harus 1 jaringan (WiFi) yang sama.
1
Buka CMD (Command Prompt) di PC/laptop server.
2
Ketik perintah: ipconfig
3
Cari baris "IPv4 Address" — contoh: 192.168.1.5 atau 192.168.100.57
4
Masukkan IP tersebut ke aplikasi HP: http://192.168.100.57:8000/api

Akses Online via Cloudflare Tunnel

Untuk akses dari luar jaringan (tanpa 1 WiFi yang sama), gunakan Cloudflare Tunnel:

1
Di server, jalankan: cloudflared tunnel --url http://localhost:8000
2
Copy link yang muncul (contoh: https://xxxx.trycloudflare.com)
3
Masukkan ke aplikasi HP: https://xxxx.trycloudflare.com/api
⚠️
Perhatian: Link Cloudflare Tunnel berubah setiap kali server di-restart. Set ulang URL di aplikasi HP jika server di-restart.

Langkah 2: Checklist Pemeriksaan

Setiap gerbong diperiksa untuk 4 kategori. Pilih kondisi B/R/T:

✅
B — Baik

Pemeriksaan normal

❌
R — Rusak

Ditemukan kerusakan

🚫
T — Tiada

Tidak ada/tidak terpasang

4 Kategori Pemeriksaan

KategoriYang Diperiksa
CCTVKondisi kamera pengawas di dalam kereta
PIDS LuarPassenger Information Display System bagian luar kereta
PIDS DalamPassenger Information Display System bagian dalam kereta
WiFiKondisi jaringan WiFi di dalam kereta
1
Untuk setiap gerbong, pilih kondisi B, R, atau T untuk masing-masing kategori.
2
Isi kolom "Keterangan" jika ada catatan tambahan (opsional).
3
Klik "Selanjutnya" untuk lanjut ke gerbong berikutnya, atau ke halaman Locotrack jika semua gerbong sudah diperiksa.
📌
Jumlah gerbong mengikuti jumlah sarana yang terdaftar di data kereta. Tambah gerbong via web admin jika diperlukan.

Langkah 3: Pemeriksaan Locotrack

Halaman Locotrack mencatat kondisi lokomotif pendukung.

1
Pilih Status locotrack: B (Baik) / R (Rusak) / T (Tiada)
2
Isi No Sarana — nomor sarana lokomotif (contoh: KA-001)
3
Isi ID Loco — identitas lokomotif
4
Isi Keterangan — kondisi atau catatan tambahan
💡
Field di atas bersifat opsional. Isi sesuai kondisi di lapangan.

Catatan Keseluruhan

1
Scroll ke bawah halaman Locotrack → temukan kolom "Catatan".
2
Ketik catatan keseluruhan untuk seluruh pemeriksaan (opsional).

Langkah 4: Simpan & Cetak PDF

1
Setelah semua data diisi, klik tombol "Simpan" di bagian bawah halaman.
2
Proses otomatis:
• Data dikirim ke server & tersimpan di database
• PDF laporan terbuka untuk preview
• PDF otomatis tercetak (auto-print)
3
Aplikasi kembali ke halaman utama "Identitas Pemeriksaan".
✅
Pemeriksaan berhasil tersimpan! Lihat riwayat pemeriksaan di menu "Riwayat" atau di web admin.

BAB D — PANDUAN WEB ADMIN

Akses Web Admin

1
Buka browser (Chrome / Firefox / Edge) di PC/laptop.
2
Akses URL: http://<IP_SERVER>:8000
Contoh: http://localhost:8000 atau http://192.168.1.5:8000
3
Halaman Dashboard akan terbuka — menampilkan ringkasan jumlah kereta, sarana, dan pemeriksaan.
💡
Web admin tidak memerlukan login. Pastikan akses terbatas untuk jaringan internal saja.

Bab D — Web Admin Panduan Pengguna WPCL

Kelola Data Kereta

1
Klik menu "Kereta" di sidebar kiri.
2
Daftar kereta akan ditampilkan dalam tabel.
3
Tambah Kereta: Klik tombol "Tambah Kereta" → isi form (No KA, Nama KA, Relasi, Jam) → Simpan.
4
Edit Kereta: Klik ikon ✏️ pada baris kereta → ubah data → Simpan.
5
Hapus Kereta: Klik ikon 🗑️ pada baris kereta → konfirmasi hapus.

Kelola Data Sarana (Gerbong)

1
Di halaman Kereta, klik nama kereta → halaman detail sarana terbuka.
2
Tambah Sarana: Klik "Tambah Sarana" → isi:
• Kode Sarana (contoh: G1, G2, G3)
• Nomor Sarana
• Seri Sarana (opsional)
• Depo Induk (opsional)
3
Klik Simpan. Sarana akan muncul di dropdown saat petugas mengisi checklist.
⚠️
Wajib: Data sarana harus diinput terlebih dahulu sebelum petugas bisa melakukan pemeriksaan. Jumlah sarana = jumlah gerbong yang akan diperiksa.

Kelola Data Pejabat

1
Klik menu "Pejabat" di sidebar.
2
Tambah Pejabat: Klik "Tambah Pejabat" → isi: Nama, NIP, Jabatan → Simpan.
3
Pejabat yang aktif akan ditampilkan di bagian tanda tangan PDF laporan.

Menambahkan Pejabat ke Pemeriksaan

1
Buka halaman "Pemeriksaan" → klik "Lihat" pada pemeriksaan.
2
Klik "Edit" → pilih pejabat dari dropdown → Simpan.

Mengedit No Dokumen & Versi

1
Di halaman daftar pemeriksaan, klik ikon 📄 pada baris pemeriksaan.
2
Modal akan muncul → isi No Dokumen dan Versi → Simpan.
💡
No Dokumen dan Versi akan ditampilkan di header PDF laporan.

BAB G — REFERENSI & TROUBLESHOOTING

Masalah Umum & Solusi

MasalahPenyebabSolusi
Aplikasi tidak bisa connect URL API salah atau server mati Cek URL di ⚙️ → pastikan IP & port benar → pastikan server jalan
"Gagal mengambil data kereta" (401) Token API tidak cocok Hubungi admin untuk memperbarui token di server
"Gagal mengambil data kereta" (404) Endpoint tidak ditemukan Pastikan URL diakhiri /api (bukan /)
Pilihan kereta kosong Belum ada data kereta Input data kereta via web admin
"Pilih Kereta" tidak bisa diklik Tidak ada sarana di kereta Input data sarana/gerbong via web admin
PDF tidak tercetak Printer tidak terhubung Cek koneksi printer → pastikan printer online
Web admin tidak bisa dibuka Server belum jalan Jalankan server: php artisan serve
Error "could not find driver" PHP extension belum aktif Buka Laragon → PHP → Extensions → centang pdo_mysql
Link Cloudflare tidak bisa diakses Link expired (server di-restart) Restart Cloudflare tunnel → update URL di HP
