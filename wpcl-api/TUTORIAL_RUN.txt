=====================================
  TUTORIAL RUN WPCL-API (Laravel)
=====================================

-------------------------------------
  BAGIAN 1: SETUP LOKAL (PC/LAPTOP)
-------------------------------------

1. Buka terminal (CMD/PowerShell)

2. Masuk ke folder project:
   cd Z:\Magang\Project\wpcl-api

3. Copy .env:
   copy .env.example .env

4. Generate APP_KEY:
   php artisan key:generate

5. Install dependencies (kalau belum):
   composer install --no-interaction

6. Jalankan migrasi database:
   php artisan migrate --force

7. Jalankan server:
   php artisan serve --host=0.0.0.0 --port=8000

8. Buka di browser:
   - Web admin:  http://localhost:8000
   - API test:   http://localhost:8000/api/kereta

-------------------------------------
  BAGIAN 2: AKSES DARI HP (LAN)
-------------------------------------

Pastikan HP & PC 1 Wi-Fi yang sama.

1. Cek IP PC:
   ipconfig
   (Cari IPv4 Address, contoh: 192.168.100.57)

2. Buka app WPCL di HP:
   - Tap ikon ⚙️ (kanan atas)
   - Ketik: http://<IP_PC>:8000/api
     Contoh: http://192.168.100.57:8000/api
   - Tap Simpan

-------------------------------------
  BAGIAN 3: AKSES DARI HP (ONLINE)
-------------------------------------

Pakai Cloudflare Tunnel supaya bisa diakses dari mana saja.

1. Download cloudflared:
   https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/

2. Jalankan tunnel:
   cloudflared tunnel --url http://localhost:8000

3. Copy link yang muncul (contoh):
   https://xxxx-xxxx.trycloudflare.com

4. Buka app WPCL di HP:
   - Tap ikon ⚙️
   - Ketik: https://xxxx-xxxx.trycloudflare.com/api
   - Tap Simpan

-------------------------------------
  BAGIAN 4: TROUBLESHOOTING
-------------------------------------

ERROR: "could not find driver"
  → Buka Laragon → PHP → Extensions → centang pdo_mysql & mysqli → Restart

ERROR: "bootstrap/cache directory must be present and writable"
  → mkdir bootstrap\cache
  → icacls bootstrap\cache /grant "Everyone:(OI)(CI)F" /T /Q

ERROR: "401 Unauthorized" / API token tidak cocok
  → Cek API_TOKEN di .env harus sama dengan yang di Flutter
  → php artisan config:clear

ERROR: "Server Error" / blank page
  → Cek error log: type storage\logs\laravel.log
  → Atau set APP_DEBUG=true di .env

ERROR: "Pilih Kereta" tidak bisa diklik
  → Database kosong, tambah data kereta via web admin dulu
  → Buka http://localhost:8000 → isi data kereta
